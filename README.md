# 🌌 COSMOS – Today in Space

A responsive space dashboard that brings real-time astronomy data to your browser using public space APIs. Explore NASA's Astronomy Picture of the Day, discover the planets of our Solar System, and stay updated with upcoming rocket launches—all in one modern interface.

## 🚀 Live Demo

https://marwaas3d.github.io/COSMOS---Today-in-Space/

---

## ✨ Features

- 🌠 NASA Astronomy Picture of the Day (APOD)
- 🪐 Explore the Solar System planets
- 🚀 View upcoming rocket launches
- 📱 Fully responsive design
- ⚡ Dynamic API integration using Fetch API
- ⏳ Loading animation while fetching data
- ❌ Error handling for failed API requests

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Tailwind CSS
- Fetch API

---

## 🌍 APIs Used

### NASA APOD API
Displays NASA's Astronomy Picture of the Day with its title, description, date, and media.

https://api.nasa.gov/planetary/apod

### Solar System OpenData API
Provides detailed information about the planets in our Solar System.

https://solar-system-opendata-proxy.vercel.app/api/planets

### SpaceDevs Launch Library API
Provides real-time information about upcoming rocket launches.

https://ll.thespacedevs.com/2.3.0/launches/upcoming

## ⚙️ Installation

Clone the repository:

```bash

```

Navigate to the project folder:

```bash
cd COSMOS---Today-in-Space
```

Open `index.html` in your browser.
